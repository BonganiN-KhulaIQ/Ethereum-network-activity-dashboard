# Ethereum-network-activity-dashboard

## Overview

This project analyzes Ethereum network activity over the last 30 days using SQL and Dune Analytics.

The dashboard explores:

- Average Transaction Fees (USD)
- Daily Transaction Volume
- Total Gas Fees Paid

The project demonstrates blockchain data analysis, SQL querying, and dashboard design using Dune Analytics.

---

## Dashboard

The dashboard contains three visualizations:

1. Ethereum Average Transaction Fee (Last 30 Days)
2. Ethereum Daily Transaction Volume (Last 30 Days)
3. Ethereum Total Gas Fees Paid (Last 30 Days)
